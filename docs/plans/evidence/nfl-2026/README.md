# NFL 2026 Evidence Ledger

Status: R0 complete and merged to `main`; R1 not started.

R0's durable recovery, salvage, baseline, tooling, and closeout evidence is
preserved in [the planning-kit evidence directory](../../planned/nfl-2026/evidence/).
Do not recreate or overwrite those provenance records when adding later-wave
packet evidence.

Add one TASK-ID.md record using the completion-evidence template for every completed or genuinely blocked packet.

The foreman may mark a wave complete only when every required task has a reviewed commit and an evidence record mapping each exit criterion to an objective command, artifact, or human observation.
