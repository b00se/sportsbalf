# R0 tooling modernization

## Scope

This packet modernizes the repository toolchain only. It does not change NFL
or MLB product code, tests, data, notebooks, models, or betslips.

## Reproducible stack

- Python 3.11 is selected by `.python-version` and constrained in
  `pyproject.toml` to `>=3.11,<3.12`.
- `uv sync` is the environment and dependency installation command.
- `uv.lock` pins the complete runtime and development dependency graph.
- Ruff provides linting and formatting (`uv run ruff check .` and
  `uv run ruff format --check .`).
- Pyright provides static type checking (`uv run pyright`).
- pytest remains the test runner (`uv run pytest`).
- Pylint is intentionally not added; Ruff covers the selected lint rules with
  less overlapping configuration.

`requirements.txt` remains available as a compatibility export for existing
pip-based users. The obsolete `nfl_data_py` line was removed because it pins
Pandas below 2 while this repository uses `nflreadpy` and Pandas 2.2. `uv sync`
and `uv.lock` are the canonical workflow.

uv cache is populated; no network access is required to execute the checks.
The nonzero format, Pyright, and pytest results are baseline classifications,
not tooling changes or hidden failures: this packet does not alter product
code or tests to make them pass.
