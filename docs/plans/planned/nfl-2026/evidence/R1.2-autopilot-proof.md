# R1.2 Controlled Autopilot Ordering Proof

Status: Accepted by operator override (2026-09-06)

## Purpose

Verify, without automation or production-draft interaction, that an uploaded
Underdog NFL Daily rankings CSV controls Autopilot selection by row order and
configured QB/RB/WR/TE position maximums.

## Preconditions

- Use the generated controlled validation CSV from the R1.1 exporter. It must
  contain the exact 12-column source schema and alter only row order.
- Select a low-risk, human-operated controlled draft. Do not use a production
  draft or automate account actions.
- Record the contest identifier, scoring mode, roster rules, configured caps,
  CSV SHA-256, local snapshot ID, and UTC observation timestamps below.
- Confirm the first test candidate is eligible under the visible roster and
  cap constraints. Do not infer eligibility from ADP or projected points.

## Procedure and Pass/Fail Record

| Check | Human procedure | Expected observation | Actual observation | Pass/Fail |
|---|---|---|---|---|
| A: row order | Manually upload the controlled CSV, join the controlled draft, and allow the first eligible Autopilot pick. | The pick is the highest-ranked eligible row in the uploaded CSV. | Pending | Pending |
| B: cap block | Manually repeat with the highest row's position cap already reached or set to block that position. | The pick is the next highest-ranked eligible, cap-permitted row. | Pending | Pending |

## Evidence to Attach After the Experiment

- Redacted screenshots or a written observation record for each check.
- The exported validation CSV hash and manifest JSON hash.
- Date/time, slate, roster/cap values, and observed player IDs (not account or
  personal identifiers).
- A statement that the test was human-operated and no automated entry or draft
  action was used.

## Decision Rule

Mark this document **Passed** only when both checks pass and the evidence is
recorded. If either check fails, mark **Failed**, preserve the artifacts, and
stop the rankings launch path: inspect other platform ordering inputs before
revising the R1.1 contract. This result is a human launch gate; code tests do
not substitute for it.
