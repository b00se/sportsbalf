# R2.2 UD-to-GSIS identity graph

Status: Ready for independent review

## Contract

`src/nfl/data/identity.py` provides a deterministic, offline identity graph
for players, teams, and games. Every mapping is keyed by explicit Underdog ID
and positive season. Resolution returns typed `resolved`, `unresolved`, or
`ambiguous` outcomes. Names are retained as diagnostics only and cannot
resolve a record. Missing identifiers, invalid seasons, season mismatches,
and one UD ID mapping to multiple GSIS IDs fail closed. The material-player
report is suitable for an export gate and is ready only when every requested
player resolves exactly once.

The frozen fixture is
`tests/testdata/nfl_identity_graph_fixture.json` with SHA-256
`db699cc9f5811e6dbd79c40e67abbb521ccbfa4cfe90afa07e21650596cdc3ed`.
