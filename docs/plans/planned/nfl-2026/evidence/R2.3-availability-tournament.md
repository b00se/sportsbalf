# R2.3 Availability Source Tournament

Status: Implemented pending independent review

The offline availability contract accepts deterministic observations from
Underdog, Sleeper, ESPN, and public roster/depth data. Each observation carries
canonical `nflverse_id`, source, normalized status, confidence, UTC observation
time, freshness, and provenance. Source acquisition remains optional; fixture
loading is network-free and hash-auditable.

Reconciliation uses explicit source weights and confidence-adjusted voting.
Fresh or explicitly valid observations are retained as reportable decisions.
Disagreement is retained as a warning and marks a conflict. The unattended gate
fails closed for missing fresh data and for unknown/conflicting high-impact
players; non-impact conflicts remain reportable without blocking.
