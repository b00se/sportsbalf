# R2.4 scorer baseline/lineage repair

Status: Superseded by the accepted R2.4 scorer closeout; retained as audit history.

Scope is limited to `projection_sources.py`, its offline regression tests, and
the source registry metadata. Baseline scoring now requires explicit public and
consensus snapshot paths, rejects path aliasing with the target or each other,
and raises `SourceAuditError` when either path is omitted. Source declarations
require a non-empty canonical family and a valid HTTP(S) registrable-domain
shape. DynastyProcess and FantasyPros normalize to the shared `fantasypros`
family, and selected baseline roles must differ in both family and domain.
