# R2.4 scorer recovery evidence

Status: Implemented; awaiting independent review.

Repair attempt 1 additionally requires prior historical rows to satisfy both
strictly earlier season/week and `as_of_utc` at or before the target row's
cutoff. The tournament selects the best eligible source for each required role
before checking publisher and registrable-domain independence, so unrelated
third sources cannot mask a colliding pair. Explicit `material_player_ids=[]`
is preserved as an empty population and returns stable zero coverage.

Repair attempt 2 rejects target rows whose as-of timestamp is after their
cutoff, selects the newest eligible baseline candidate per target key, and
maps DynastyProcess and FantasyPros to one `fantasypros` lineage family.
First-row historical MAE is defined as `0.0` when no prior observation exists;
public and consensus MAE still score every valid target with their own
denominators.

Scope is limited to `projection_sources.py` and its offline regression tests.
The scorer now validates all season/week/timestamp/numeric fields through
`SourceAuditError`, applies each target row's own cutoff, and uses history only
from strictly earlier season/week observations. Public and consensus fixture
values are loaded from their separate snapshots and scored for every valid
target row, including the first row, with independent denominators.

Material IDs are case/whitespace normalized, blanks excluded, duplicate IDs
counted once, and coverage is clamped to `[0, 1]`. Baseline independence now
requires both normalized publisher lineage and registrable-domain lineage to
be distinct.
