# R2.5 As-of feature store

Status: Repair attempt 1; pending independent review

The deterministic `AsOfFeatureStore` accepts target rows keyed by canonical
`nflverse_id` and an explicit timezone-aware `as_of_utc` cutoff. Normalized
provider, projection, availability, or identity-derived evidence is eligible
only when its source timestamp is at or before that row's cutoff. Optional
event/game/slate columns scope a match, and each selected value retains source
timestamp, provenance, and freshness seconds. Missing/naive timestamps,
unresolved canonical IDs, missing provenance, duplicate source observations,
and required-but-unavailable evidence fail closed.

Acceptance tests include same-player future projection perturbation, future
availability/source-row perturbation, strict timestamp validation, and
unresolved-identity rejection. Future rows cannot alter historical output.

## Repair attempt 1 — production acceptance surface

Added `src/fantasy/adapters/nfl/feature_store.py` as the production-facing
adapter. `SnapshotEvidence` requires nonempty snapshot ID, SHA-256, and
manifest reference. The builder consumes canonical target player/game/as-of
rows and snapshot-backed source tables, rejects integer/string/naive timestamps,
rejects unscoped sources unless explicitly marked global-safe, and excludes the
target game and all later evidence. It emits rolling prior means for plays,
pace, neutral pass rate, opportunity share, routes, snaps, opponent strength,
rest, weather, spread/total, role, availability, and projections, alongside
missingness/fallback rates and snapshot provenance on every output row.

## Repair attempt 2 — reviewer P1 closure

Snapshot evidence now requires a lowercase 64-character SHA-256 matching the
canonical CSV serialization (or an explicitly pinned manifest digest). Blank
provenance and blank scoped game/event/slate values fail closed. Production
construction always requires nonempty evidence; there is no opt-out path.
Source rows are sorted by timestamp before selection, and target-game rows are
excluded. The adapter is exported from `src.fantasy.adapters.nfl`.

The output includes deterministic per-feature missingness and fallback flags,
plus a JSON missingness summary and season. When a player has no current prior,
numeric features use prior-season values where available and then a global
hierarchical prior. Future perturbation tests compare model features while
allowing the expected snapshot hash change.
