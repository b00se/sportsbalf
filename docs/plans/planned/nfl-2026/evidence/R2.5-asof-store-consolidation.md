# R2.5 As-of Store Consolidation

Status: Pending independent review

## Decision

The reviewed production adapter at
`src/fantasy/adapters/nfl/feature_store.py` is the single R2.5 as-of feature
store. Direct import evidence found no callers of
`src/nfl/features/asof_store.py` outside its obsolete dedicated test, so the
duplicate module and that test were removed.

The adapter test suite now retains the displaced safety coverage in equivalent
form: pre-cutoff projections and availability rows are unchanged by a mutated
future row, and a blank provenance field fails closed. The test suite also
asserts that the removed legacy import path is absent, preventing a second
production implementation from reappearing unnoticed.
