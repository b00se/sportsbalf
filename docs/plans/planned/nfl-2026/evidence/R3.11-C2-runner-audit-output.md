# R3.11-C2 Runner Audit Output

Status: Implemented; repair 1 amended; pending independent review and real archive execution.

## Scope

This packet closes the runner-output portion of the R3.11-B review. The
archive-backed baseline runner now persists both evaluator prediction frames:
`weekly_predictions.csv` and `season_predictions.csv`. The run manifest records
their SHA-256 digests, row counts, columns, evaluation mode/status, and the
explicit outer-fold keys used to produce each report. Metrics files have the
same metadata, so an output bundle can be audited independently of the in-memory
return value.

Fetch-mode provenance is derived from the concrete provider's declared
provenance when available, including source URL/version and installed package
name/version. Otherwise the runner records the provider identity and an explicit
`unknown` version; it never substitutes the runner's `pip` version or a
hardcoded provider name. Archive-read mode carries the immutable archive
manifest's source and package provenance into the output manifest.

The raw pre-reconciliation provider contract remains a separate C1 seam. This
packet does not alter provider implementations or duplicate handling.

## Repair 1 (2026-09-11)

The first real archive attempt exposed nflverse aggregate/non-player rows with
missing player identity and position. Canonicalization now excludes rows whose
normalized position is not QB/RB/WR/TE before identity validation, while
supported-position rows with missing identity still fail closed. The offline
regression covers both cases.
