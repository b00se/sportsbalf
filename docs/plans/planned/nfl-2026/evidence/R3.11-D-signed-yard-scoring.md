# R3.11-D Signed-Yard Fantasy Scoring

Status: Implemented; awaiting independent foreman review.

## Scope

NFLverse observed player-week statistics can contain negative yardage (for
example, a quarterback losing rushing yards on a sack). The fantasy scorer now
accepts finite signed values only for `passing_yards`, `rushing_yards`,
`receiving_yards`, and `rare_rush_yards`. Opportunity and event/count fields
remain finite and nonnegative, including attempts, completions, targets,
receptions, touchdowns, interceptions, fumbles lost, and conversions.

## RED/GREEN evidence

RED condition: before this packet, the scorer routed yard fields through the
global nonnegative validator, so a valid negative-yard player-week failed
closed instead of producing a score; there was no regression test covering the
NFLverse case.

The regression tests verify signed passing, rushing, receiving, and rare
receiver rushing yardage contributes to half-PPR scoring (`12.6` and `-0.7`
fixtures), while negative pass attempts, receptions, passing touchdowns, and
fumbles lost each raise `ValueError`.

## Gate impact

This is a scoring correctness repair only. It does not run network ingestion,
alter archive/provider behavior, or authorize R4. The archived backtest must
be rerun after the R3.11 runner/provider repair packets and independently
reviewed before any R4 decision.
