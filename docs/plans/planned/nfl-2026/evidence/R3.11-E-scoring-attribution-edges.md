# R3.11-E Scoring Attribution Edges

Status: Implemented; focused packet pending foreman integration review.

## Scope

The NFLverse weekly source contains valid receiving attribution rows where a
player has receiving yards and/or receiving touchdowns but zero receptions.
The scorer therefore must not infer that `receiving_tds <= receptions` is a
universal invariant. This packet removes only that invalid relation. It keeps
the meaningful fail-closed opportunity checks, including completions plus
interceptions versus pass attempts, receptions versus targets, and passing or
rushing touchdowns versus their corresponding opportunities.

## Source-shaped regression

The offline regression uses a canonical source-shaped `J.Gibbs` component row:
`receiving_yards=19`, `receiving_tds=1`, `receptions=0`, and `targets=0`.
Half-PPR scoring correctly returns `19 * 0.1 + 1 * 6 = 7.9` points. The same
shape covers the observed NFLverse edge for J.Gibbs (2024 week 3) and J.Allen
(2024 week 13), where receiving attribution includes touchdown/yards with zero
receptions; the test does not require network access or embed an archive.
