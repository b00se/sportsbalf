# R3.12-A Direct-FP archive candidate evaluator

Status: Implemented; pending independent review.

The new `src/nfl/models/direct_fp_evaluation.py` adapter evaluates the existing
`direct_fantasy_points_benchmark` on strictly prior weekly rolling-origin and
season-held-out folds. It returns the baseline evaluator's metric schema plus
`outer_fold`, `actual`, and explicit `window` fields, preserving fold-level
predictions for audit. It requires three outer folds for eligibility and never
returns `promoted`.

Evidence command:

```text
.venv/Scripts/pytest.exe -q tests/test_nfl_direct_fp_evaluation.py
.venv/Scripts/ruff.exe check src/nfl/models/direct_fp_evaluation.py tests/test_nfl_direct_fp_evaluation.py
git diff --check
```

No network or archived data run is performed in this packet. R3 remains gated
until the runner produces real fold manifests and a comparison tournament.
