# R3.12-B archived component adapter

Status: implemented, focused review pending.

The adapter in `src/nfl/models/archived_component_adapter.py` normalizes
canonical NFLverse weekly player rows and partitions them into the exact QB,
RB, and WR/TE history schemas accepted by the existing component projectors.
It requires supported player identity, position, integer season/week, every
position-specific component, and unique player-week keys. Unsupported player
positions, malformed values, conflicting aliases, and negative count/opportunity
values fail closed. Yardage remains signed because negative rushing/receiving
yardage is a valid observed outcome. Receiver routes are required and are never
estimated from targets.

The adapter emits history frames only. It does not emit target rows and never
copies target-week outcome fields into features; callers must supply identity
and calendar-only targets to the projectors.
