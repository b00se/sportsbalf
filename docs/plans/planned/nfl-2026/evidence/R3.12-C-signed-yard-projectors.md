# R3.12-C signed-yard component projector repair

Status: complete for this packet; downstream archived execution remains gated.

## Scope

The archived NFLverse component adapter preserves signed net yardage, including
negative passing, rushing, receiving, and rare-rush yardage. The three
component projectors previously rejected those valid history rows because their
normalizers applied a blanket nonnegative check. This packet makes the
projector contracts match the adapter without weakening opportunity validation:

- QB `passing_yards` and `rushing_yards` accept finite signed values.
- RB `rushing_yards` and `receiving_yards` accept finite signed values.
- Receiver `receiving_yards` and `rare_rush_yards` accept finite signed values.
- Attempts, routes, targets, receptions, touchdowns, team caps, and other
  count/rate inputs remain finite and nonnegative; invalid negative values still
  fail closed.
- Infinite values remain rejected for every field.
- Receiving touchdowns are validated as nonnegative counts but are not required
  to be less than receptions: completed NFLverse rows can attribute a receiving
  touchdown with zero recorded receptions for both receivers and running backs.
  The projector's forecast output remains opportunity-capped.
