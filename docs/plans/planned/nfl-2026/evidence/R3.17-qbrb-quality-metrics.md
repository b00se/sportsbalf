# R3.17: QB/RB quality-metric contract

Status: Complete for metric reporting. This does not promote a candidate or
allow R4.

## Delivered metrics

The archived QB/RB component evaluator now emits both fold-level and aggregate
rows, explicitly distinguished by `aggregation`. Aggregate rows carry
`outer_folds`, `valid_folds`, `status`, and `eligible`. Any aggregate metric
with fewer than three valid outer folds has a `NaN` value and `inconclusive`
status.

In addition to component MAE and fantasy-point MAE/point-forecast CRPS, the
evaluator now reports:

- Fold-local Spearman rank correlation, aggregated only across valid folds.
- Fold-local top-k recall with `k=min(3, slate size)` and deterministic
  `player_id` tie breaking.
- Explicit `calibration` rows marked unavailable. These are deterministic
  point forecasts with no interval or probability forecast, so empirical
  calibration is not claimed.

The fold target remains identity and calendar only; target-week outcomes enter
only after projection for scoring.
