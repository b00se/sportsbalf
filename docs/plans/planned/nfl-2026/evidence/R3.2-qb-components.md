# R3.2 QB component projections

Status: Implemented; packet commit recorded below.

This packet adds an offline-safe, deterministic QB component projection API in
`src/nfl/models/qb_components.py`. It projects passing attempts, completions,
passing yards/touchdowns/interceptions, and rushing attempts/yards/touchdowns.
The API uses a typed configuration, conservative empty-history priors, optional
team pass-attempt opportunity, and QB historical share. All source observations
used for a target are strictly earlier than that target's season/week. An
explicit `(season, week)` `as_of` cutoff further limits eligible history.

The projection enforces nonnegative component values and caps completions at
projected attempts. `rolling_origin_compare` evaluates pass-attempt MAE using
expanding historical folds and compares against the declared historical global
mean baseline; the model is promoted only when it ties or beats that baseline.
