# R3.22: WR/TE route-backed component evaluation

Status: Complete and unpromoted. R4 remains blocked.

## Protocol

The evaluator accepts canonical weekly outcomes and the separately
manifest-backed `identified_receiver_routes` artifact. It aggregates explicit
multi-team route rows only after validating exact team keys and position
consistency. Each fold constructs history from route-bearing WR/TE observations
strictly before its origin. The projector receives target rows containing only
`receiver_id`, `position`, `season`, and `week`; target routes and outcomes are
joined after projection solely for scoring and coverage.

All canonical WR/TE targets are scored, including first-fold prior fallback
targets. This avoids conditioning the target cohort on a target-week route.
