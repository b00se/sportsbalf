# R3.24: Weekly regressor bakeoff

Status: Complete, research-only, and unpromoted. R4 remains blocked.

## Scope

This narrowly reopens R3 to test whether fixed direct fantasy-point regressors
can improve the weekly forecast benchmark. Weekly fold mean fantasy-point MAE
is the selection objective at the user's direction. The ranking is explicitly
research-only because it is calculated on the same outer folds used to compare
the candidates; it is not a promotion or an ensemble-selection result.

Every candidate uses only player observations strictly before the target week:
shifted all-history mean, trailing four-observation mean, prior count, and
same-season prior mean. Four fixed, seeded candidates are fit independently in
each fold: Ridge, Random Forest, Extra Trees, and Gradient Boosting. No target
week feature, response, hyperparameter selection, or blend weight enters a
fit.
