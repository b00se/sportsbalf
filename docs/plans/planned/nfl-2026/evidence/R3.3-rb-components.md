# R3.3 RB component projections

Status: Implemented and committed; awaiting independent wave review.

This packet adds `src/nfl/models/rb_components.py`, a typed deterministic
offline-safe API for bottom-up running-back projections. It derives rush
attempts, targets, rushing and receiving yards, receptions, and rushing and
receiving touchdowns from supplied historical rows strictly before each
target's season/week boundary. Optional team rush/target volumes cap and
scale individual opportunity by historical share. Availability is explicit
and conservative: inactive/out produce zero components, explicit
probabilities are bounded to [0, 1], and uncertain statuses default to 0.5.
No distribution mixtures are included.

The API rejects invalid/non-finite/negative values, duplicate player-calendar
keys, unknown availability statuses, and receptions greater than targets.
Rolling-origin comparison builds each fold's target frame from identity and
calendar keys only, so test-fold team volumes and other target inputs cannot
affect the projection. Promotion is reported only when trailing-mean MAE ties
or beats the expanding-mean baseline.
