# R3.8 Ensemble Tournament Evidence

Status: complete

## Scope

Implemented only `src/nfl/models/projection_ensemble.py`,
`tests/test_nfl_projection_ensemble.py`, and this evidence record. The API is
offline-safe and deterministic: it canonicalizes player/calendar keys, rejects
missing, misaligned, non-finite, boolean, or duplicate inputs, and preserves
the three source identities in scored output.

## Method and gates

`run_nested_ensemble_tournament` evaluates strictly ordered calendar folds.
Each outer fold builds chronological inner validation folds strictly inside its
outer training rows. A fixed deterministic source/blend weight grid is selected
by inner validation only, then applied to the outer fold; target-fold outcomes or
predictions never enter selection. Internal, underdog, consensus, and blend
candidates are declared in fold score output. Promotion requires the selected
aggregate MAE to tie or beat the best component baseline and at least three
outer rows; otherwise the result explicitly reports non-promotion. Fewer than
three scored rows produce an `inconclusive` uncertainty marker and never claim
an edge.

Reported metrics include component loss, fantasy-point MAE, deterministic
empirical CRPS (equal to absolute error for point forecasts), Spearman rank
correlation, top-k recall, and calibration by position (with an explicit ALL
bucket when position labels are unavailable).

Repair attempt 2 additionally enforces NFL season 1920--9999 and week 1--22,
accepts only integral calendar values (plus canonical numeric strings), rejects
sentinel player IDs, and reports ranking metrics per outer calendar before
averaging. Promotion is based on distinct outer folds, not player-row count;
position labels are preserved for grouped calibration.
