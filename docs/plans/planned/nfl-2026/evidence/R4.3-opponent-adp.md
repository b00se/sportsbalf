# R4.3 Stochastic Opponent Model Around Archived Underdog ADP

Status: Implemented (offline stochastic rank scenarios; no live quote, draft, upload, account, or entry behavior)

The typed `OpponentAdpConfig` and `simulate_opponent_adp` API accepts a
player table with unique `player_id` and finite positive archived `adp`.
Each scenario perturbs ADP with zero-mean normal noise at explicit
`dispersion`, then assigns unique integer ranks with canonical player-ID
tie-breaking. Input metadata is retained and provenance explicitly records
`archived_underdog_adp_no_live_quote`. Canonical ordering makes output stable
under input row reordering; a private seeded NumPy generator makes scenarios
exactly reproducible. The model is transparent and claims no predictive edge.
